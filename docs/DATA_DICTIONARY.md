# Data Dictionary

## coverage-data
- `code`: ISO-3 Country Code
- `name`: Country Name
- `year`: Year of record
- `antigen`: Vaccine antigen
- `coverage`: % coverage

## incidence-rate-data
- `code`: ISO-3 Country Code
- `year`: Year
- `disease`: Disease code
- `incidence_rate`: Incidence rate based on denominator

## reported-cases-data
- `cases`: Number of reported cases

## vaccine-introduction-data
- `intro`: Introduction status

## vaccine-schedule-data
- `schedulerounds`: Dose count for schedule
